# JARVIS UI prototypes

This folder preserves the interactive UI concepts developed for the JARVIS assistant so future Claude and Codex sessions can review and improve them alongside the implementation.

## Canonical design

- `jarvis-future-complete-ui.html` — current editable UI source.
- `jarvis-future-complete-ui-preview.html` — directly openable browser preview of the current design.

The current design includes the assistant core, task activity, multimodal controls, memory, study and research concepts, the system pipeline, tools and safety, diagnostics, and a Natural Earth world-news map.

## Earlier concepts

- `jarvis-hybrid-ui.html`
- `jarvis-project-workflow.html`
- `jarvis-real-3d.html`
- `jarvis-roadmap-ui.html`
- `jarvis-ui-concepts.html`

Each source has a matching `*-preview.html` file that can be opened directly in a browser.

## Important status note

These files are design prototypes, not the production JARVIS application. Some content is sample data. Labels such as **verified**, **early slice**, **experimental**, and **planned** are intentionally used to separate implemented capabilities from roadmap concepts. Recheck those labels against the repository whenever the implementation changes.

Edit the source file first. Preview wrappers are generated copies and should be regenerated after source changes.
